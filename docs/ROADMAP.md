# NexusOS Roadmap

## Phase 0: Foundation
Canonical architecture, contracts, policy, Tender Scout manifest and validation.

## Phase 1: Tender Scout
Wrap the working Hermes + Discord agent with NexusOS jobs, audit and capability semantics without rewriting it.

## Phase 2: Ops & Security
Uptime, TLS, dependency, vulnerability and backup monitoring. Diagnose automatically; gate consequential remediation.

## Phase 3: Software Factory
Developer, Test, Reviewer, Security and Deployment agents working through GitHub issues/PRs with independent review and CI evidence.

## Phase 4: Business Operations
Lead qualification, proposal drafts, quotations, follow-ups, invoice signals and client intelligence. External sends and financial commitments remain gated.

## Phase 5: Executive Layer
Morning brief, calendar preparation, decisions, project health and exception reporting.

## Phase 6: Productisation
Extract tenant-safe components only after NexusHub proves reliability, security, cost and operational value internally.

## First 30 days

1. Put Tender Scout behind the common manifest.
2. Implement validation and append-only event logging.
3. Build the first Discord approval flow.
4. Add one low-risk Ops agent.
5. Measure success, false positives, cost, intervention rate and time saved.
